# Sample Configs

Each file in this folder is a ready-made starting point for a different parenting style.

Use them like this:

1. Open one of the sample files.
2. Copy all of its contents.
3. Replace the contents of `safe-youtube.config.jsonc` with what you copied.
4. Edit the names, blocked terms, channels, or video links to fit your child.
5. Save the file and let Vercel redeploy.

These sample files are only starting points. You should still review the blocked words, channels, and videos yourself.

At the top of each sample file, `simpleSettings` gives the easiest on/off switches.

- `1` means yes
- `0` means no

In `categories`:

- `label` is the text a child sees on the button
- `searchFor` is the phrase Safe YouTube searches for after the child taps that button

Emoji labels in `categories` are fine and can make topic buttons easier for younger kids to recognize.
